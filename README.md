# Kissa — install & first run
1. Copy `out/StoryApp.apk` to an Android 8.0+ phone and open it (allow "Install unknown apps" for your file manager/browser when asked).
2. Open **Kissa** → onboarding: your name, he/she, dialogue language (Hinglish default).
3. Get a free Gemini key: https://aistudio.google.com/apikey → Create API key → paste in onboarding or Settings → AI → Save key → "Test connection".
4. Home → "Corridor Crossings" → Enter scene. Type or tap the mic (grant microphone permission when asked).
5. Voices come from the phone's text-to-speech engine. For best Hindi/Indian English voices install "Speech Services by Google" and its Hindi + English (India) voice data (Settings → Accessibility → Text-to-speech).
