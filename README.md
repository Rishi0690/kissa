# Kissa — install & first run
1. Copy `out/StoryApp.apk` to an Android 8.0+ phone and open it (allow "Install unknown apps" for your file manager/browser when asked).
2. Open **Kissa** → onboarding: your name, he/she, dialogue language (Hinglish default).
3. Get a free Gemini key: https://aistudio.google.com/apikey → Create API key → paste it on the last onboarding page (or Settings → Story AI & voices) → **Test & save**. It is stored encrypted on the phone and sent only to Google.
4. Home → "Corridor Crossings" → Enter scene. Type or tap the mic (grant microphone permission when asked).
5. Character voices: Gemini natural voices with your key while its small free voice quota lasts (≈10 lines/day per model), then Microsoft neural voices (free, no key, needs internet). The phone's own text-to-speech is the last fallback and is labelled "Basic voice". Settings → Voice & audio shows which engine is speaking and lets you pick your own character's voice.
